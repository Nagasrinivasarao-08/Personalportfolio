# Personalportfolio

Full-stack developer & AI engineer portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

## Features
- **Hero Section**: Responsive design with video backdrop and headline intro.
- **About Section**: Highlighting education at IIT Guwahati and Google Student Ambassador role.
- **Areas of Expertise**: 8 core technical capability cards.
- **Experience & Education**: Timeline of professional background.
- **Skills**: Interactive categorization of tech stack.
- **Selected Work**: Showcasing production client websites (TrustLayerLabs) and products.
- **Contact Form**: Direct project inquiry form.

## Tech Stack
- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, AOS
- **Deployment**: Vercel
